# Week 3 \- Password Cracking Labs

## Overview

This repository contains my Week 3 cybersecurity practical exercises focused on password security, hash analysis, and password recovery techniques.

The project consisted of two laboratory modules:

- **Week3\-ProjectModule1:** Password Cracking with John the Ripper (JTR)
- **Week3\-ProjectModule2:** Password Cracking with Networkwalks Tools

All activities were completed within an authorized training environment using laboratory\-provided files. The objective was to understand how password hashes are generated, how password recovery tools operate, and why strong password security is essential.

---

## Learning Objectives

During these labs, I developed practical experience in:

- Understanding password hashing concepts
- Identifying and analyzing password hashes
- Using John the Ripper for password recovery
- Understanding password\-cracking workflows
- Utilizing online hash\-analysis and password\-recovery tools
- Recovering passwords from intentionally protected PDF files
- Evaluating risks associated with weak passwords
- Applying ethical hacking techniques in a controlled environment

# Module 1: Password Cracking with John the Ripper

## Tool Used

**John the Ripper (JTR)**

John the Ripper is a widely used password auditing and recovery tool commonly employed in authorized security assessments, penetration testing, and cybersecurity training environments.

## Practical Activities

This module focused on working with password hashes and recovering passwords from authorized laboratory datasets.

### General Workflow

1. Obtain the authorized hash or laboratory file
2. Identify the hash format
3. Prepare the hash for analysis
4. Execute the password recovery process
5. Verify the recovered password
6. Document findings and results

### Skills Demonstrated

- Hash identification
- Hash analysis
- Password auditing
- Password recovery
- Command\-line tool usage
- Ethical security testing

# Module 2: Password Cracking with Networkwalks Tools

## Tools Used

- Networkwalks Hash Calculator
- Networkwalks Password Cracker

These browser\-based tools provide an alternative approach to password recovery without requiring local software installation.

## Practical Activities

The task involved recovering the password of an intentionally protected PDF supplied as part of the cybersecurity training laboratory.

### Workflow

1. Obtain the authorized PDF file
2. Upload the file to the Networkwalks Hash Calculator
3. Generate the password hash
4. Copy the extracted hash
5. Submit the hash to the Networkwalks Password Cracker
6. Execute the recovery process
7. Verify the recovered password

### Skills Demonstrated

- Password hash extraction
- Online password recovery tools
- Password analysis
- Security testing methodologies
- Laboratory documentation

# Key Lessons Learned

Through these practical exercises, I learned that:

- Passwords are protected using cryptographic hashes rather than being stored in plain text
- Weak or predictable passwords are vulnerable to recovery attacks
- Password hashes require appropriate protection and storage
- Strong, unique passwords significantly improve security
- Understanding offensive techniques helps security professionals build stronger defenses
- Password security plays a critical role in overall cybersecurity posture
